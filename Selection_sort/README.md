# Selection Sort

## Description

Selection Sort is a simple comparison-based sorting algorithm that repeatedly selects the smallest element from the unsorted portion of the array and places it at the beginning.

The algorithm:

- Finds the minimum element in the unsorted portion
- Swaps it with the current position
- Repeats until the array is sorted

## Program File

- `selectionsort.c` → Source code
- `output.txt` → Program output

## Compilation

```bash
gcc selectionsort.c -o selectionsort
```

```bash
./selectionsort
```

## Algorithm Type

- Sorting Algorithm

## Concepts Used

- Array Traversal

## Complexity

- Time Complexity: O(n²)
- Space Complexity: O(1)
